# Taraborelli FIAT - Análisis de Micro-Influencers

Sistema de análisis y evaluación de micro-influencers para campañas de marketing de Taraborelli FIAT, especialmente enfocado en el Hot Sale de Mayo.

## Objetivo

Identificar y evaluar creadores de contenido potenciales que puedan amplificar el mensaje de Taraborelli FIAT mediante contenido auténtico y engagement genuino con su audiencia.

## Estructura del Proyecto

```
├── framework/
│   ├── ANALISIS_FRAMEWORK.md
│   └── metricas_evaluacion.json
├── analistas/
│   └── influencer_template.md
└── reportes/
    └── [reportes generados]
```

## Características Principales

- **Framework de análisis** basado en 7 dimensiones clave
- **Scoring automático** con ponderación configurable
- **Evaluación de riesgos** y oportunidades
- **Integración de datos** (followers, engagement, audiencia)
- **Recomendaciones estratégicas** para colaboraciones
